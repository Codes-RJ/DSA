## Learning Order

1. Start with `iostream`.
2. Move to `vector` and `string`.
3. Learn `algorithm` for sorting and searching.
4. Learn adapters, ordered containers, and unordered containers.
5. Add vocabulary types such as `optional` and `variant` when the problem benefits from them.
6. Use the remaining pages as references rather than reading every header linearly.

## DSA Cheat Sheet

- `iostream` for `cin`, `cout`, `cerr`, and `getline`
- `vector` for dynamic arrays and iteration
- `string` for text handling and parsing
- `algorithm` for `sort`, `find`, and binary search helpers
- `cmath` for numeric operations
- `random` for modern pseudo-random number generation
- `optional` for a value that may be absent
- `variant` for one value selected from a fixed set of types
