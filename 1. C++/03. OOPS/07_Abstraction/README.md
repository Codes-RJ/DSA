# Abstraction and Interfaces in C++

> **Minimum standard:** C++17

## Study Order

1. [Abstract classes](01_Abstract_Classes.md)
2. [Interfaces in C++](02_Interfaces_in_Cpp.md)
3. [Abstract versus concrete classes](03_Abstract_vs_Concrete.md)
4. [Design patterns](../12_Design_Patterns/README.md) — canonical pattern catalog

## Learning Outcomes

- Separate required behavior from implementation details.
- Design a minimal interface around a stable responsibility.
- Explain pure virtual functions and virtual destruction.
- Compare runtime interfaces with templates and callable objects.
- Avoid inheritance where composition or a value type is simpler.
